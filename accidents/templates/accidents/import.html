How it works

  • The file and its sheets can have any name. What matters is the column headings: they must be the same as in the export.
  • One sheet must hold the reports (with at least Report number and Date of accident). Sheets for vehicles, passengers and pedestrians are optional.
  • Files from the accident database are also read (sheets with headings such as ACCIDENT KEY, REPORT NUMBER, DATE).
  • A file that is not accident data is refused, and nothing is saved.
  • Codes are read as they are written: a report number with the year attached (237/15 is report 237 of 2015), the region as its number (1 is Ashanti), the town as its town/village code (0101 is Ashanti, Kumasi), and the police station as its code (04086 is Nsawam).
  • Rows on the other sheets are linked to a report by their accident column, written as number/year (for example 790/2021).
  • You see a summary first. Nothing is saved until you click Import.
  • Reports already in the system are skipped, so importing the same file twice is safe.
  • Sketch pictures are not imported. Add them on each report afterwards.
  • The reminders of the report form (for example a missing time or GPS location) are not applied. Imported reports keep the status given in the file.
